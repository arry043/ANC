## 6. Measurement Accuracy Limitations

You expressly acknowledge that:
1. Throughput calculations are derived from operating system kernel byte counters (`getifaddrs`) sampled over variable, non-real-time intervals (~1 second).
2. Displayed throughput represents an **approximate, instantaneous average** over the preceding sampling period and does not reflect continuous physical wire speed or microsecond packet burst rates.
3. Network interface transitions, sleep/wake cycles, virtual network adapters (such as VPNs and virtual machine bridges), and operating system scheduling jitter can introduce temporary measurement interruptions or resets.
4. Measurements encompass all traffic traversing the selected interface, including both local network (LAN) transfers and external internet (WAN) traffic.
5. The Application must not be relied upon as an official benchmark for contractual internet speed guarantees or service provider level agreements (SLAs).
